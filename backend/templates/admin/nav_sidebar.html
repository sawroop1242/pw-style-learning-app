This version shows the same six groups as the console home, so the way you find something on the home page is the way you find it here. This is a fragment: admin/base.html includes it inside its own `{% block nav-sidebar %}`. It is not a page and must not extend anything. The markup keeps Django's shape — `.module > table > tr > th[scope=row]` — because admin/js/nav_sidebar.js filters on `th[scope=row] a` and toggles the grandparent . Restyling the rail is fine; changing its shape is not. {% endcomment %}
